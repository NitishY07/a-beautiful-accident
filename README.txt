A BEAUTIFUL ACCIDENT — DEDICATED VERSION 💗

This website is dedicated to your best friend. The gallery is intentionally designed for photos of her only.

FIX FOR THE BROKEN PHOTO ICONS
The broken image icons in the earlier preview mean the browser could not find the image files at the paths in the HTML. This project expects the photos inside assets/images, not beside index.html.

ADD YOUR 10 PHOTOS
Put your files in:
assets/images/

Rename them exactly:
photo1.jpeg
photo2.jpeg
photo3.jpeg
photo4.jpeg
photo5.jpeg
photo6.jpeg
photo7.jpeg
photo8.jpeg
photo9.jpeg
photo10.jpeg

If Windows hides file extensions, turn on File Explorer > View > Show > File name extensions before renaming. Avoid names like photo1.jpg.jpg.
The website already uses .jpeg paths to match your current photo filenames.

ADD YOUR 2 VIDEOS
Put them in assets/videos/ and name them video1.mp4 and video2.mp4.

OPTIONAL MUSIC
Put a music file at assets/music/music.mp3. Music starts only when the visitor clicks the Music button.

RUN LOCALLY
1. Extract this ZIP.
2. Add the media files as above.
3. Open the folder in Visual Studio Code.
4. Install the Live Server extension.
5. Right-click index.html > Open with Live Server.
You can also double-click index.html, but Live Server is better for testing.

IMPORTANT
- Keep the assets folder next to index.html.
- Do not move index.html away from the assets folder.
- If a photo is missing, the gallery now shows a helpful filename instead of a broken image icon.
- This website uses relative paths and can be deployed as a static site to Vercel.
- Only publish photos/videos that she is comfortable having on a shareable website.
